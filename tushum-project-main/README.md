# Түшүм - Спутниковый мониторинг сельхозземель

Онлайн платформа для анализа состояния сельхозземель Кыргызстана с использованием спутниковых данных.

## Быстрый старт

### 🚀 Запуск общедоступного сервера (доступен во всей сети)

**Windows (рекомендуется):**
1. Дважды кликните на файл `start-server.bat`
2. Скрипт автоматически определит ваш IP-адрес и покажет адреса доступа
3. Сервер будет доступен:
   - Локально: http://localhost:8000/login.html
   - В сети: http://[ВАШ_IP]:8000/login.html (на других устройствах)

**Или через PowerShell:**
1. Запустите `start-server.ps1`
2. Скрипт автоматически покажет все адреса доступа

**Вручную через командную строку:**
```bash
# Общедоступный доступ (во всей сети)
python -m http.server 8000 --bind 0.0.0.0
```

**Важно:** 
- Сервер автоматически доступен во всей локальной сети
- Убедитесь, что файрвол разрешает входящие соединения на порт 8000
- На других устройствах используйте IP-адрес, который покажет скрипт

### Настройка файрвола для общедоступного доступа

**Автоматически (рекомендуется):**
1. Запустите `allow-port-8000.bat` от имени администратора
   - Правой кнопкой мыши → "Запуск от имени администратора"
2. Или через PowerShell: `allow-port-8000.ps1` (от имени администратора)

**Вручную:**
1. Откройте "Брандмауэр Защитника Windows"
2. Нажмите "Дополнительные параметры"
3. Выберите "Правила для входящих подключений" → "Создать правило"
4. Выберите "Порт" → TCP → Укажите порт 8000
5. Разрешите подключение

**Важно:** 
- Не открывайте файлы напрямую (file://), используйте локальный сервер!
- Для доступа из интернета потребуется настройка роутера (проброс портов)

## Решение проблем

Если страница не открывается:
1. Убедитесь, что Python установлен: `python --version`
2. Проверьте, что порт 8000 свободен
3. Используйте адрес `http://localhost:8000/login.html` (не `https://`)
4. Откройте консоль браузера (F12) для просмотра ошибок
